## 🔄 迭代機制

### 自動檢測規則
1. **重複討論檢測**: 系統會自動識別重複的討論主題
2. **決策變更檢測**: 當決策發生變更時，會自動標記並記錄原因
3. **進展對比**: 每次會話都會與前次進展進行對比
4. **技術債務追蹤**: 自動追蹤未解決的技術債務

```markdown
### 會話 #[SESSION_ID]

[PROGRESS_UPDATES]

#### 下一步行動
[NEXT_ACTIONS]

#### 技術債務
[TECHNICAL_DEBT_ITEMS]
```
