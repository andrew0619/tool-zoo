# Tool Zoo 網站測試指南

## 🧪 **測試概述**

本指南提供完整的 Tool Zoo 網站測試方法，包括自動化測試、手動測試和性能測試。

## 🚀 **快速開始**

### **1. 啟動開發服務器**

```bash
# 安裝依賴
npm install

# 啟動開發服務器
npm run dev
```

### **2. 運行自動化測試**

```bash
# 運行完整測試套件
node test-website.js

# 或者使用 npm 腳本
npm run test:website
```

## 🛠️ **手動測試指南**

### **1. 瀏覽器測試**

#### **Chrome DevTools**
1. 打開 Chrome DevTools (F12)
2. 切換到 "Network" 標籤
3. 重新載入頁面
4. 檢查資源加載時間
5. 查看是否有 404 錯誤

#### **響應式測試**
1. 打開 DevTools
2. 點擊設備模擬器圖標
3. 選擇不同設備尺寸
4. 測試頁面佈局和功能

#### **性能測試**
1. 打開 DevTools
2. 切換到 "Performance" 標籤
3. 開始記錄
4. 執行用戶操作
5. 停止記錄並分析結果

### **2. 功能測試**

#### **智能引導測試**
1. 清除瀏覽器本地存儲
2. 訪問主頁
3. 檢查是否顯示引導
4. 測試引導步驟
5. 測試跳過功能

#### **認證流程測試**
1. 訪問註冊頁面
2. 填寫註冊表單
3. 提交並檢查驗證
4. 登入測試
5. 測試密碼重置

#### **健康檢查測試**
1. 訪問健康檢查頁面
2. 等待數據載入
3. 檢查各項指標
4. 測試圖表交互
5. 測試響應式設計
