## 🛠️ **開發工具**

### **可用腳本**
```bash
# 開發
npm run dev                    # 啟動開發服務器
npm run build                  # 構建生產版本
npm run start                  # 啟動生產服務器

# 測試
npm run test:website           # 運行網站測試
npm run test:e2e              # 端到端測試
npm run test:coverage         # 測試覆蓋率

# 代碼質量
npm run lint                   # 代碼檢查
npm run lint:fix              # 自動修復
npm run type-check            # 類型檢查

# 部署
npm run deploy                # 部署到 Vercel
npm run health-check          # 健康檢查
```

### **協作腳本**
```bash
# 設置協作環境
./scripts/claudable-setup.sh

# 停止協作環境
./scripts/claudable-stop.sh

# 安全部署
./scripts/deploy.sh
```
