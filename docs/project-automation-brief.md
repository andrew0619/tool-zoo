# 專案自動化記憶更新系統 Brief

## 📋 系統概述

這是一個完整的專案開發自動化記憶更新系統，用於：

- 自動記錄開發會話和決策
- 追蹤專案進度和技術債務
- 管理迭代和決策變更
- 防止重複討論和錯誤

---

## 🚀 快速部署

### 5分鐘快速開始

#### 步驟 1: 運行設置腳本

```bash
# 給腳本執行權限
chmod +x scripts/setup-automation-system.sh

# 運行設置腳本（替換 your-project-name 為你的專案名稱）
./scripts/setup-automation-system.sh your-project-name [部署模式]

# 部署模式選項:
#   minimal  - 精簡部署 (預設)
#   hybrid   - 混合部署
#   full     - 完整部署
```

#### 步驟 2: 複製 AI 助手記憶設定

將 `docs/ai-assistant-memory.md` 的內容複製到你的 AI 助手的記憶設定中。

#### 步驟 3: 開始使用

查看 `docs/README.md` 了解如何使用各個文件。
